# Audition Lab — 最初の試聴

このアプリはプラグインでもDAWでもありません。PySide6のデスクトップ画面から、
C++の再生・フリーズ処理と既存SDKを使います。配布バイナリの検証対象はLinux x86_64です。
Python 3.11以降とrequirementsの導入が必要で、単一の自己完結EXEではありません。

## 起動

ZIPを展開し、そのフォルダーで実行します。

```sh
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements-audition.txt
bash start-audition.sh --demo
```

通常は「音声を開く」でWAV/FLAC/AIFF/OGGを選ぶか、画面へドロップします。
出力デバイスとレートを選択し、低い試聴音量から開始してください。
音声デバイスが無い場合でも、合成・比較・WAV保存は使えます。

## 速度0で、その位置の音を保持する

波形上をクリックして原音位置を選び、「再生」を押します。
速度は0〜4倍。**0はフリーズ、1は等速、4は4倍速**です。
Fキー／フリーズボタンで速度0と直前の正の速度を切り替えます。
Spaceは一時停止で、フリーズとは別の操作です。

ピッチは半音差で指定します。**0 stは音程変更なし**、範囲は-24〜+24 stです。
フリーズ中もピッチ・対応するフォルマント設定を変更できます。
PVでは局所スペクトルと周波数を保持し、出力の位相を進めます。時間領域モードは
保持位置周辺の短い波形を探索・重畳します。共通の完成済みWAVループではありません。
各方式は新transportの試用実装であり、既存SDKと同一の音声出力とは限りません。

## 新6方式を同じフリーズ位置で比較

1. ネイティブタブで原音位置、速度、ピッチ、フォルマント、出力秒数を指定します。
2. 「6方式を現在位置・同条件で比較」を押します。速度0のまま実行できます。
3. 完了すると比較タブへ移動します。選択欄で方式を切り替え、「比較音源を再生」。
   「選択WAVと記録を保存」で無加工のfloat32 WAVとJSON記録を保存できます。

全モードを同じ読み込み済みPCM・同じ原音位置から新しい合成履歴で開始します。
WAV長は指定した0.1〜120秒。途中中止では未完のWAVを削除し、完了・中止・未対応を
各モードの結果へ残します。既存ファイルは上書きしません。

フォルマント保持を指定すると、非対応の時間領域3モードはunsupportedになります。
Offへ勝手に変えて全件成功と表示することはありません。6方式すべてを同条件で
比較する際は、共通に対応するOffを選択します。

比較は新しい履歴からの合成であり、直前の再生バッファを録音したものではありません。
試聴音量をWAVへ適用したり、方式ごとにゲイン・時間位置を合わせたりはしません。
一時的な比較結果は終了時に消えます。必要なWAVは閉じる前に保存してください。

## 既存main SDKの全5品質モードを比較

比較タブの「5方式を同条件で比較」は、既存SDKの実CLIを実行します。
WSOLA General/Transient/Efficient、PV General/Transientが対象です。
WSOLAは速度0.25〜4・±24 st・保持Off、PVは速度0.5〜2・±12 stが対象です。
旧SDKの速度0は未対応で、新transportへ自動的に置き換えません。

過去の研究枝のmulti-resolution、phase-gradient、HPSS、可変窓などすべてを
ネイティブフリーズへ移植したわけではありません。「比較音源を開く」は生成済み
研究WAVを再生する機能であり、未移植アルゴリズムの実行機能ではありません。

## 検証範囲

GUI操作・C++合成・WAV保存・部分的な音声書込み・故障／無デバイス処理は自動試験済み。
実DAC／スピーカーへの物理的な再生はこの開発環境では未確認です。
Qt/PythonキューとOSバッファがあるため、ハードリアルタイムや瞬時の無遅延変更は
保証しません。逆再生、ライブ入力、Windows/macOS配布は今回の検証範囲外です。
詳細な使い方・依存ライブラリはREADME_JA.mdを参照してください。
