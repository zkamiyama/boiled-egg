## Numerical convention

Consume real-signal full spectra with NSDGT local phase origin, unnormalized forward FFT. Work on bins0..M/2, then explicitly impose Hermitian symmetry. Reject nonfinite/non-Hermitian input beyond3e-6*max(1,frame peak); keep DC/Nyquist real with their original signs/magnitudes. Store the imaginary change implied by the real-spectrum convention as a diagnostic. No hidden original PCM is passed to phase generation or synthesis.

Backward time gradient: principal(phi[n]-phi[n-1]-omega_k*delta_a)/delta_a+omega_k. PV integrates using the corresponding synthesis hop. PVDR uses the mean of backward/forward gradients (equation15), one-sided endpoint derivatives, centered principal frequency-bin differences (equation18) with one-sided bin edges, and trapezoidal time/frequency integration. For irregular hops explicitly use the arithmetic mean of the two normalized directional slopes; do not label this a general second-order derivative on a nonuniform grid.

Frequency-edge propagation scales by alpha (b_s/b_a); time propagation uses actual synthesis delta_b. Synthesis centers are round(alpha*analysis_center), not cumulative rounded hops. This fixes the source/output clock convention; full experiment uses only integer alpha1/2/4. First frame starts from measured phase, not an independently solved initial phase. No unity bypass: alpha1 must pass through analysis/phase/synthesis and any reconstruction error is reported.

Heap order: descending magnitude, then previous-frame before current-frame, then lower bin index. For each significant current bin, insert the previous-frame node, as Algorithm1 line5 specifies; each current bin is integrated once. Threshold tol=1e-6 times max(previous,current magnitude). Insignificant phases use a fixed integer hash of seed20260920/frame/bin instead of entropy randomness. This is an explicit reproducibility profile difference. Keep a predecessor trace (initial/time/frequency/low threshold), gradients, magnitudes and coefficient/output hashes. Zero mathematical coefficients synthesize zero; nonzero audio fixtures may not pass as zero outputs.

Kernel budgets: FFT powers2 in16..16384,2..4096 frames,<=8388608 full complex coefficients; centers strictly increasing in[0,288000),constant alpha1..4. Validate sizes, mode, tolerance, budget, input and schedule before output writes; a failure must not partially modify caller output. Calls synchronous with independent local state; allocations permitted for NRT. Not installed or linked to product SDK.
