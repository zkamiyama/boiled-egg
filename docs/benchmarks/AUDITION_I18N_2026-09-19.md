## 実装と利用方法

画面右上の「言語 / Language」で「日本語 / English」を選択する。
アプリ再起動・原音再読込みは不要。UIで選択した言語はQSettingsの
boiled-egg/AuditionLab、ui/languageに保存し、次回起動時に復元する。
初回と不正な保存値は日本語。保存失敗時は現在の表示を維持して警告する。

```sh
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements-audition.txt
bash start-audition.sh --language en --demo
# または
bash start-audition.sh --language ja
```

--languageはその起動中だけの指定で、保存済み設定を上書きしない。
保存操作は画面での言語変更時に行う。1ウィンドウの利用を対象とする。

翻訳対象は操作ボタン、タブ、説明、モード表示、保持方式表示、波形案内、
再生/フリーズ表示、比較進捗・結果、既存のアプリログ、ダイアログ題名とフィルター。
Qtの標準翻訳カタログが利用可能なら日本語で使用する。
OS標準ダイアログの一部表示はOS設定に従う場合がある。
ファイル名・デバイス名・未知の外部診断は原文を保持する。

切替は表示のみ。選択項目のdataにある数値IDやoff/harmonic/monophonicは
翻訳せず、現在の速度・ピッチ・フォルマント・音量・原音位置・比較選択を維持する。
pause/seek/resetや音声キュー消去を呼ばず、ジョブを中止しない。
既存のJSON記録と生WAVを書き換えない。速度0=フリーズ、pitch0st=音程変更なし
という意味もそのまま維持する。
